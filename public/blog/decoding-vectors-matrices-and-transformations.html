Decoding Vectors, Matrices, and Transformations

December 4, 2024 / 6 min read Read on Substack ↗

A matrix in technical terms just represents a linear transformation…

What does this word linear transformation mean? Well, for that, first, let’s understand what a vector is…

Many of you reading this must have heard the word vector at some point, and there are different thought processes on what it is. These thought processes are based on how certain fields perceive and use them.

Let’s take the case of physics. They treat a vector as something that points to a magnitude in a direction in space. For example, in 2 dimensions, a vector represents an arrow with a value, and its direction is specified. It can exist anywhere in space, and it’s not bound as long as its magnitude and direction are not disturbed.

In computer science, a vector is shown as a list of numbers in a certain order. Order is important here because it defines how the vector proceeds for further usage. It’s like a list that tells us how to process that data.

In mathematics, the idea is a mixture of both of the above thoughts. Here, vectors are seen as objects that follow specific rules for operations like addition and scalar multiplication.

Now, let’s talk about two very important things in the world of vectors:

addition (a + b) and scalar multiplication (5a).

  • Addition of two vectors means just combining them together. Imagine two arrows pointing in different directions. If you add them, you simply start at the tail of one arrow and finish at the tip of the other, creating a new arrow that represents the sum of both.

  • Scalar multiplication means stretching or shrinking the vector by a certain factor. If you multiply a vector by a number (let’s say 5), you’re essentially making the vector 5 times longer, but it still points in the same direction.

So now that you have an idea of what a vector is, let’s see what a linear transformation means.

A linear transformation is a function that takes a vector and changes it in a way that preserves two important things: addition and scalar multiplication. This means that if you have two vectors, v and w, and a scalar a, the linear transformation T will satisfy these two properties:

  1. Additivity:

    T(v+w)=T(v)+T(w)

    This means that if you transform the sum of two vectors, you can just transform each vector separately and then add them up.

  2. Homogeneity (or Scalar Multiplication):

    T(a⋅v)=a⋅T(v)

    This means that if you scale a vector by a number, then you can first scale the vector and then transform it, or you can first transform the vector and then scale it by the same number. Both methods give the same result.

These two rules are what make a transformation linear. So, a linear transformation doesn’t distort the basic relationships between vectors—it simply changes them in a predictable and consistent way.

Now, let’s talk about how this idea of a linear transformation is connected to matrices and matrix multiplication.

In simple terms, a matrix is just a tool that helps us apply a linear transformation to a vector. Think of it as a machine where you input a vector, and the machine spits out another vector that has been transformed in some way. It could be stretched, rotated, reflected, or compressed, depending on the matrix.

To understand this better, let’s break down what’s happening here.

Intuition Behind Matrix Multiplication

When we multiply a matrix by a vector, what’s really happening is that we’re applying a linear transformation to the vector. Here’s one way to think about it:

  1. Matrix Columns as Directions: The columns of matrix A tell us how the vector is going to be changed. The first column tells us how the x-component of the vector should be transformed, and the second column tells us how the y-component of the vector should be transformed. Each column of the matrix can be thought of as a direction in space.

  2. Weighted Sum: When we multiply a matrix by a vector, we’re taking a weighted sum of the columns of the matrix. A weighted sum just means adding up a set of numbers where each number is multiplied by a weight (the components of the vector).

So, in the matrix multiplication

we are using the x- and y-components of vector v (which are x and y) to weight the columns of A. This results in a new vector that is a combination of those columns, weighted by the original vector’s components.

Matrix Multiplication as a Transformation

You can think of matrix multiplication as applying a transformation to the entire coordinate system. Here’s an analogy to help:

Imagine a coordinate system where you have two axes: the x-axis and the y-axis. Now, a matrix is like a set of instructions for changing how those axes look. If you apply a matrix to the coordinate system, you’re stretching, rotating, or reflecting the axes. Every vector in this system will now be transformed according to these new axes.

When you multiply a matrix by a vector, you’re essentially mapping the original vector into this new coordinate system, where the basis vectors (which are the fundamental direction vectors of the system) are transformed by the matrix. The vector v is then represented in this new coordinate system by a weighted sum of the transformed basis vectors.

Now that we understand how matrix multiplication works as a linear transformation, let’s look at why matrix multiplication is so crucial in deep learning, especially in models like large language models (LLMs).

In deep learning, everything that happens—from how the model processes data to how it makes predictions—is powered by matrix multiplication. Each layer in a deep learning model takes in a set of data (like words, sentences, or images) and applies a series of linear transformations, which are carried out using matrices.

Matrix multiplication is the core operation of deep learning models, making it central to understanding how these models work.
