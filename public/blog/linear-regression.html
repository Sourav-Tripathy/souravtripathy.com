Linear Regression

The Fundamental Statistics and Machine Learning Algorithm

May 29, 2024 / 6 min read Read on Substack ↗

Linear regression is a fundamental statistical technique that enables us to explore and quantify the relationship between variables. At the very basic level, its meaning lies in its name, which contains two terms: linear and regression.

Linear - The term "linear" refers to a straight-line relationship between variables. In the context of linear regression, it implies that the change in the dependent variable can be described as a linear combination of the independent variables. Simply put, if you plot the relationship on a graph, the result is a straight line.

Regression - The term "regression" comes from the concept of "regressing" or returning to a mean. In statistics, regression analysis is a method for modeling the relationship between a dependent variable and one or more independent variables. It helps in predicting the value of the dependent variable based on the known values of the independent variables.

To sum up -

Linear Regression is a supervised machine learning algorithm where the predicted output is continuous and has a constant slope. It’s used to predict values within a continuous range, rather than trying to classify them into categories.

General form of a linear regression model is:

Y = β0 + β1X1 + β2X2 + ... + βnXn + ε

Where:

  • Y is the dependent variable (the variable you want to predict or explain).

  • X1, X2, ..., Xn are the independent variables (the predictor variables).

  • β0 is the intercept (the value of Y when all independent variables are zero).

  • β1, β2, ..., βn are the coefficients or slopes associated with each independent variable.The coefficients (β1, β2, ..., βn) measure the change in the dependent variable for a one-unit change in the corresponding independent variable, while holding all other variables constant.

  • ε is the error term,that accounts for the variability in Y that cannot be explained by the linear relationship with X. It captures the effects of all other factors not included in the model.

    For linear regression to provide reliable and accurate results, several assumptions must be met:

  • Linearity: The relationship between the dependent and independent variables should be linear.

  • Independence: Observations should be independent of each other.

  • Homoscedasticity: The residuals (errors) should have constant variance across all levels of the independent variables.

  • Normality: The residuals should be normally distributed.

  • No Multicollinearity: Independent variables should not be highly correlated with each other.

Now that an understanding of linear regression is made, we must know how to fit the model i.e finding the optimal parameters (coefficients and intercept) that best describe the relationship between the dependent variable and the independent variables in the dataset. Here the concept of cost function arises. Lets understand that

Cost function: The cost function (often the mean squared error or MSE) measures how well the model's predictions match the actual data. It is defined as the average of the squared differences between the observed values and the predicted values.

MSE = (1/N) Σ(Yi - Ŷi)^2

Where N is the number of observations, Yi are the actual values, and Ŷi are the predicted values from the model.

But this is not enough for fitting, we need to optimize the cost function to find those parameter values that minimize the cost and here optimization algorithms comes into play. There is algorithms like OLS (Ordinary Least Square) , Gradient Descent but OLS is most commnly used in linear regression , so, lets understand that.

Ordinary Least Squares (OLS)

OLS is a method to estimate the parameters by minimizing the sum of the squared residuals (differences between observed and predicted values). The steps involved in OLS are:

  1. Define the Residuals: Residuals (ei) are the differences between the observed values (Yi) and the predicted values (Ŷi):

ei = Yi - Ŷi

  1. Sum of Squared Residuals (SSE): Calculate the sum of the squared residuals, which is the cost function to be minimized:

SSE = Σ(ei^2)

  1. Minimize the Cost Function: Find the parameter values (β0, β1, ..., βn) that minimize the sum of squared residuals. This involves solving the following normal equations:

X^T * β = X^T *Y

Where X is the matrix of input features, β is the vector of parameters, and Y is the vector of observed values. (X^T means X matrix transposed and * means multiplication)

Lets understand through a practical example.

Practical Example

Consider a simple linear regression with one independent variable (X) and one dependent variable (Y). Suppose we have the following data:

X = {1,2,3,4}

Y = {2,3,5,7}

We want to fit the linear model: Y = β0 + β1X

  1. Initial Guess: Let's start with the initial guesses β0 = 0 and β1 = 1. The initial model equation is: Y = 0 + 1X

  2. Compute Predictions: With the initial guesses, we can compute the predicted values (Ŷ) for each X:

    For X = 1, Ŷ = 0 + 1(1) = 1

    For X = 2, Ŷ = 0 + 1(2) = 2

    For X = 3, Ŷ = 0 + 1(3) = 3

    For X = 4, Ŷ = 0 + 1(4) = 4

  3. Compute Residuals and Cost: Residuals (ei) = Observed Value (Yi) - Predicted Value (Ŷi)

    For X = 1, e1 = 2 - 1 = 1

    For X = 2, e2 = 3 - 2 = 1

    For X = 3, e3 = 5 - 3 = 2

    For X = 4, e4 = 7 - 4 = 3

    So,Sum of Squared Residuals (SSE) = e1^2 + e2^2 + e3^2 + e4^2 = 1^2 + 1^2 + 2^2 + 3^2 = 1 + 1 + 4 + 9 = 15

  4. Optimize Parameters: To find the optimal values of β0 and β1 using OLS, we need to solve the normal equations: X^T * β = X^T *Y (where β is the matrix containing β0 and β1 as elements). On solving we get,

    β0 = 0.5 β1 = 1.5

After fitting, the optimized model equation is: Y = 0.5 + 1.5X

This model minimizes the sum of squared residuals (SSE = 0) for the given data(On repeating steps 1 ,2 and 3 we get SSE=0), meaning it provides the best fit to the linear relationship between X and Y. Therefore, the fitted linear regression model that best describes the relationship in the data is:

Y = 0.5 + 1.5X
